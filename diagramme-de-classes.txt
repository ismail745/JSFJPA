DIAGRAMME DE CLASSES - APPLICATION E-COMMERCE

1. CLASSE: Utilisateur
   - id: Long (PK)
   - nom: String
   - prenom: String
   - email: String
   - motDePasse: String
   - adresse: String
   - telephone: String
   - dateInscription: Date
   - Relations:
     * Un utilisateur peut avoir plusieurs commandes (1:N)
     * Un utilisateur possède un panier (1:1)

2. CLASSE: Panier
   - id: Long (PK)
   - dateCreation: Date
   - Relations:
     * Un panier appartient à un utilisateur (N:1)
     * Un panier contient plusieurs lignes de panier (1:N)

3. CLASSE: LignePanier
   - id: Long (PK)
   - quantite: Integer
   - prixUnitaire: Double
   - Relations:
     * Une ligne de panier appartient à un panier (N:1)
     * Une ligne de panier référence un produit (N:1)

4. CLASSE: Produit
   - id: Long (PK)
   - nom: String
   - description: String
   - prix: Double
   - stock: Integer
   - image: String
   - dateAjout: Date
   - Relations:
     * Un produit appartient à une catégorie (N:1)
     * Un produit peut être dans plusieurs lignes de panier (1:N)
     * Un produit peut être dans plusieurs lignes de commande (1:N)

5. CLASSE: Categorie
   - id: Long (PK)
   - nom: String
   - description: String
   - Relations:
     * Une catégorie peut contenir plusieurs produits (1:N)

6. CLASSE: Commande
   - id: Long (PK)
   - dateCommande: Date
   - statut: String (ENUM: EN_ATTENTE, VALIDEE, EXPEDIEE, LIVREE, ANNULEE)
   - montantTotal: Double
   - Relations:
     * Une commande appartient à un utilisateur (N:1)
     * Une commande contient plusieurs lignes de commande (1:N)

7. CLASSE: LigneCommande
   - id: Long (PK)
   - quantite: Integer
   - prixUnitaire: Double
   - Relations:
     * Une ligne de commande appartient à une commande (N:1)
     * Une ligne de commande référence un produit (N:1)

RELATIONS PRINCIPALES:
- Utilisateur (1) --- (1) Panier
- Panier (1) --- (N) LignePanier
- LignePanier (N) --- (1) Produit
- Produit (N) --- (1) Categorie
- Utilisateur (1) --- (N) Commande
- Commande (1) --- (N) LigneCommande
- LigneCommande (N) --- (1) Produit

Ce diagramme de classes représente la structure de base d'un site e-commerce avec:
- Gestion des utilisateurs (internautes)
- Gestion du catalogue de produits (vitrine)
- Gestion du panier d'achat
- Gestion des commandes
